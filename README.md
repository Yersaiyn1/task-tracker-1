# Mini Task Tracker

Веб-приложение для ведения списка задач на React + TypeScript + Vite.
Интерфейс на русском языке: добавление задач, отметка выполнения, удаление
и фильтры. Задачи сохраняются в localStorage браузера, поэтому после
обновления страницы список восстанавливается.

## Технологии

| Компонент | Что использовать |
| --- | --- |
| Язык | TypeScript |
| Интерфейс | React + Vite |
| Хранение | localStorage браузера (ключ `tasks`) |
| Тесты | Vitest |

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Приложение откроется на локальном адресе, который выведет Vite
(обычно http://localhost:5173).

## Запуск тестов

```bash
npm test
```

## Сборка

```bash
npm run build
```

Готовые файлы появятся в каталоге `dist`. Локально проверить собранную
версию можно командой `npm run preview`.

## Как работает приложение

1. Пользователь вводит название задачи и нажимает «Добавить» или Enter.
   Пробелы по краям удаляются. Если название пустое, показывается сообщение
   «Введите название задачи».
2. Новая задача получает уникальный ID и статус «К выполнению».
3. Чекбокс рядом с задачей переключает статус между «К выполнению» и
   «Выполнена». Завершённая задача выделяется зачёркнутым текстом.
4. Кнопка «Удалить» запрашивает подтверждение с названием задачи.
5. Фильтры «Все», «К выполнению» и «Выполненные» ограничивают список.
   Для пустого списка и пустого результата фильтра показываются понятные
   сообщения.
6. Задачи и счётчик следующего ID сохраняются в localStorage. После удаления
   задачи её ID не используется повторно: счётчик только растёт.
7. Если браузер не смог сохранить изменения (например, переполнено хранилище
   или включён запрет cookies), показывается сообщение об ошибке, а список
   остаётся в состоянии до действия.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `src/tasks.ts` | Модель задач: добавление, переключение статуса, удаление, фильтры |
| `src/storage.ts` | Загрузка и сохранение состояния в localStorage, ошибки записи |
| `src/useTaskStore.ts` | Хук состояния: связывает логику задач с сохранением |
| `src/App.tsx` | Интерфейс: форма, фильтры, список задач, подтверждение удаления |
| `src/tasks.test.ts` | Тесты логики задач |
| `src/storage.test.ts` | Тесты загрузки и сохранения, включая ошибку записи |

Все действия доступны с клавиатуры: поле ввода, кнопки фильтров, чекбоксы и
кнопки удаления — стандартные элементы, между которыми можно перемещаться
клавишей Tab. Интерфейс адаптивный: на узких экранах кнопка «Добавить»
переносится под поле ввода, а строки задач перестраиваются.
